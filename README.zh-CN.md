Project Title : TRINETRA AI
Team ID : TH11830

1. Overview
   TRINETRA AI is an artificial intelligence-based "Third Eye" for public safety. It is specifically intended to oversee huge events such as Simhastha 2028 by anticipating, averting, and reacting to crowd disasters. The system combines real-time tracking, multilingual voice instructions, and automated notifications to guarantee safety and minimize stampede threats.

2. Problem & Solution
   Problem Statement:
   The 2025 Prayagraj Kumbh Mela experience overcrowding with more than 40 crore tourists, resulting in a devastating stampede that took the lives of 30+. The then-existent AI solutions were restricted to image monitoring and not having predictive analytics, voice notifications, and real-time response systems.

Solution:
TRINETRA AI provides a closed-loop AI-based system that identifies risk, initiates multilingual voice notifications, alerts authorities, and sends emergency services in real-time — providing proactive intervention to avoid disasters.

3. Logic & Workflow
   Data Collection: Real-time video streams from AI-powered cameras at ghats, bridges, and intersections.
   Processing: Computer vision using AI forecasts crowd density, surges, and hazards.
   Output: Insta view dashboard (LCD display) shows alerts; SMS delivered to officials; emergency services alerted.
   User Side: Multilingual audio instructions received by public loudspeakers by crowd.
   Admin Side: Officials see real-time updates, receive auto-notifications, and monitor response.

4. Tech Stack
   Frontend: HTML
   Backend: PYTHON
   Database: SQL
   AI/ML: Python (Predictive Analytics, Computer Vision, YOLOv8)
   Communication: Email gateway for notifications

5. Future Scope
   Multi-user & multilingual support in regions.
   Nationwide deployment for mass-level events and festivals.
   Additive Manufactured advance display panel to show alternate routes to avoid case of stampede.
